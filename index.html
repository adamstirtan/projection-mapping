Important: a saved project stores corner positions, opacity, surface order, media type and media file name only. Media files themselves are not saved — re-upload them after loading.

Tip: start with the test pattern, align the four corners to the real surface, then switch the source to your image or video. Keep the projector as square-on to the surface as you can; extreme angles lose resolution.
